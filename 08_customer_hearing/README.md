# 08 Customer Hearing

## Overview

This document describes an infrastructure hearing sheet for customer environment confirmation.

## Purpose

This section simulates customer environment confirmation before introducing or operating a healthcare SaaS infrastructure system.

In infrastructure work, it is important to understand the customer's network, server, client PCs, security requirements, backup status, and operation rules before making changes.

## Hearing Flow

Confirm customer information
↓
Check network environment
↓
Check server environment
↓
Check client environment
↓
Check security requirements
↓
Check backup status
↓
Check operation and support requirements
↓
Identify risks and notes

## Main Check Points

- customer site type
- number of users
- number of client PCs
- network environment
- fixed global IP address
- existing server
- virtualization environment
- security requirements
- backup method
- restore test status
- maintenance window
- emergency contact
- service stop tolerance

## Why This Is Important

A server may work correctly in a lab environment but fail in a real customer environment if network restrictions, firewall settings, client PC conditions, or operation rules are not checked.

Customer hearing helps prevent installation trouble and operation trouble.
